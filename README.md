level-generation pipeline. This is not a browser imitation: the deliverable is
`out/CLINE CIRCLES.gmd`, genuine GD level data.

## Build the level

```
python -m clinecircles build --optimize     # writes out/CLINE CIRCLES.gmd
python -m clinecircles info                 # timing / section plan
python3 tools/crosscheck_gmdkit.py 'out/CLINE CIRCLES.gmd'
python3 tests/test_core.py
```

## Import it into Geometry Dash

1. Install **Geode** (the GD 2.2 mod loader) and the **GDShare** mod.
2. Copy `out/CLINE CIRCLES.gmd` somewhere you can reach from the game.
3. In GD: **Create → GDShare → Import**, and pick the `.gmd` file.
   (Some GDShare builds read the file from a fixed folder; the mod's page
   documents the exact path.)
4. The level opens in the editor as a normal, editable level. Press play to
   test it.
5. The song is a Newgrounds track: in the editor pick song id **533927**. If
   it does not load, your build has a different song allow-list — see
   `docs/PLAYTEST.md`.

If GDShare is unavailable, `out/CLINE CIRCLES.levelstring.txt` contains the
same level as a plaintext level string for any string importer.
